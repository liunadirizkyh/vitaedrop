# 📄 VitaeDrop

VitaeDrop is a modern, responsive Curriculum Vitae (CV) builder application built with **Next.js** and **React**. It empowers users to create, preview, and export professional-grade CVs in real-time, all within a clean and intuitive user interface.

## ✨ Key Features

- **Real-Time Preview**: Instantly see how your CV looks as you type, designed with a realistic A4-page layout system.
- **PDF Export**: Generate perfectly scaled, print-ready PDF files of your CV with a single click.
- **Dynamic Formatting**: Automatic pagination and layout adjustments ensure your content fits seamlessly across multiple pages.
- **Premium Integrations**: Built-in support for secure payment gateways via Midtrans.
- **Responsive Design**: Carefully crafted with Tailwind CSS for an optimal experience across different screen sizes.

## 🚀 Technologies Used

- **Framework**: Next.js (App Router), React
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **PDF Generation**: `react-to-print`, `pdf-lib`
- **Payments**: Midtrans Client
- **Type Safety**: TypeScript

## 🛠️ Getting Started

### Prerequisites
Make sure you have Node.js and npm (or yarn/pnpm/bun) installed on your machine.

### Installation

1. Clone the repository and navigate into the project directory:
   ```bash
   git clone https://github.com/liunadirizkyh/vitaedrop.git
   cd vitaedrop
   ```

2. Install the dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the application in action.
